# 淘金币助手 v1.0

一个基于 **Shizuku + OCR** 的淘金币自动任务小工具。

## 软件原理

本项目完全不依赖 Android 无障碍服务，核心流程如下：

1. 使用 **Shizuku** 执行 `screencap` 获取当前屏幕；
2. 使用 **ML Kit OCR** 识别页面文字与任务区域；
3. 根据识别结果判断当前页面状态；
4. 再通过 **Shizuku** 执行点击、滑动、输入、返回、启动淘宝等操作。

也就是说，运行链路是：

`Shizuku 截图 → OCR 识别 → 状态机判断 → Shizuku 点击/滑动/输入`

## 软件功能

- 自动从淘宝首页进入 **淘金币** 页面；
- 自动识别并处理 **赚更多金币 / 展开 / 任务列表**；
- 支持 **新旧版淘金币界面**，会通过 OCR 自动识别任务面板特征，无需手动切换；
- 支持 **普通浏览 / 搜索任务 / 跨应用跳转任务**；
- 支持 **自定义黑名单、跳转任务名单、搜索任务名单、普通浏览名单**；
- 支持 **顶部悬浮状态条**（可选）与一键停止；
- 遇到 **安全验证** 会自动停止，避免误操作；
- 纯截图 OCR 识别，尽量规避 UC WebView 旧节点问题；
- 当普通任务已经执行完/只剩黑名单任务时，会先**强制滑回任务面板顶部复查未完成任务**：如果发现新的可执行任务则回到主循环继续执行；确认没有可执行任务后，才进入收尾领奖。经典版检查“今日累计奖励”，新版也会检查可见的“领取奖励/立即领取”；
- 运行日志保留更多历史记录，并在每次开始执行时加入分隔线，方便排查多轮测试。

## 运行方法

### 1）Shizuku 权限

- 先安装并启动 **Shizuku**；
- 在本 App 中点击 **“授权 Shizuku”**；
- 确认淘宝已经安装并登录。

> 非 Root 场景下，手机重启后通常需要重新启动 Shizuku 服务，这是 Shizuku 的正常使用方式。

### 2）悬浮窗权限（可选）

如果你想使用顶部悬浮状态条：

- 打开 App 内的 **“顶部悬浮状态条”** 开关；
- 按提示授予 **“显示在其他应用上层”** 权限。

如果不开启悬浮状态条，则 **不需要** 这个权限。

## v1.0 当前特性

- 淘宝首页导航使用宽范围 OCR，并对“领淘金币”合并行做位置估算。
- 任务列表使用较高分辨率 OCR，黑名单支持保守模糊匹配，降低形近字误识别造成的误执行。
- 新旧版淘金币任务面板共用同一套状态机，无需手动选择版本。
- 收尾阶段始终先向上滑回顶部，并复查是否还有未完成且不在黑名单中的任务；有则继续执行，没有才领奖并结束。
- 经典版只有明确识别到“今日累计奖励”时才会点击累计奖励槽，不再使用固定坐标兜底，避免误点第一条任务。
